# feat-128 — ปรับแนวมือและแขนขณะกิน

- ผู้ใช้ยืนยันว่าจุดที่ผิดคือท่ามือและแขน แก้ pole ข้อศอกให้เปลี่ยนตามช่วงตัก/ยก และปรับทิศอุปกรณ์ที่จานให้แนวข้อมือต่อกับแขนยิ่งขึ้น พร้อมคงศอกไว้นอกด้านลำตัว
- ขณะตัก มุมระหว่างมือกับปลายแขนจาก ~65° เหลือ ~22°; unit test ตรวจมุม <40°, ศอกอยู่นอกลำตัว, อุปกรณ์สัมผัสจาน/ปาก และข้อต่อไม่พลิกฉับพลัน; สร้าง customer full/lite GLB ใหม่
- Chrome production E2E ผ่านช่วงกินและเก็บภาพที่ 1× แปดจังหวะ (screens/eat-contact-sheet.png); ภาพแสดงท่าในหนึ่งผังและมุมกล้อง ไม่ใช่การรับรองท่าทางทุกกรณี
- npm test: 111 files / 1,304 tests ผ่าน; typecheck และ boundary scan ผ่าน; init บน Windows ยังติด dirname/python3 launcher
- ข้อจำกัดที่ยังเหลือ: นิ้วมือในโมเดลใช้กระดูกมือเดียว ไม่มีข้อต่อนิ้วแยก จึงยังไม่สามารถกำอุปกรณ์ได้จริง
