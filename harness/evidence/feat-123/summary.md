### แสงตามเวลาจริง

ตรึงเวลาเครื่องด้วย `page.clock.setFixedTime` (เปลี่ยนเฉพาะ `Date` ไม่แตะ timer/rAF ฉากจึงยังวาดปกติ)
วันที่ใช้: 2026-06-21 เขตเวลา +07:00

| เวลา | ความสว่างเฉลี่ยของฉาก |
|---|---|
| เช้า 07:30 | 0.9069 |
| เที่ยง 12:00 | 0.9174 |
| เย็น 17:45 | 0.8686 |
| กลางคืน 21:30 | **0.8203** (ยังอ่านผังออก ไม่ดำสนิท) |

- เที่ยงสว่างกว่ากลางคืนจริง (0.9174 > 0.8203) และภาพสองเวลาไม่เหมือนกัน
- หมุนกล้องครบ 4 ด้าน: 0.9069 → 0.9242 → 0.8990 → 0.9046 → **0.9068** — กลับมุมเดิมแล้วความสว่าง
  กลับมาเท่าเดิม (ต่าง 0.0001) แปลว่าแดดยึดกับโลกของร้าน ไม่ได้หมุนตามกล้อง
- ร้าน 2 × 2 ม. และ 30 × 30 ม. วาดได้และสว่างปกติ (0.9069 / 0.9413)
- `prefers-reduced-motion`: ใช้ฉาก SVG นิ่ง ไม่มี canvas WebGL
- โหมดพิมพ์: ฉากยังอยู่ครบ ไม่มี error (การวัด pixel ขณะ emulate print ไม่เสถียรใน Chromium
  การยืนยันว่า interval ของนาฬิกาแสงหยุดอยู่ใน unit test `lighting/clock.test.ts`)

## ข้อที่ยังตรวจไม่ได้ และเหตุผล (ไม่ถือว่าผ่าน)

1. **Baseline 80 ลูกค้า + 8 พนักงาน** — ผังตัวอย่างคาเฟ่ 8 × 6 ม. มี **6 ที่นั่ง** ฉากที่วัดได้จึงมี
   ลูกค้า 1–2 คน เกณฑ์ข้อนี้ระบุไว้เองว่า "ถ้าผังรองรับ" แต่ยังไม่มีผังขนาดใหญ่ที่สร้างฉากนั้นได้
   จึง **ยังไม่มีตัวเลข baseline ของฉากหนาแน่น** ต้องทำผัง fixture ขนาดใหญ่ก่อน
2. **Draw calls และ GPU memory** — `renderer.info` ของ three.js ไม่ถูก expose ออกมาที่หน้าเว็บ
   วัดจากภายนอกไม่ได้ ต้องมี diagnostic hook ฝั่งแอป ซึ่งอยู่นอก write_scope ของ feat-123
3. **ภาพยืนยัน คราบ / การเช็ดโต๊ะ / ท่าถือเสิร์ฟ แยกเป็นข้อ ๆ** — สถานะเหล่านี้ไม่มีอะไรใน DOM ให้จับ
   และอ่าน snapshot จากหน้าเว็บไม่ได้ ปัจจุบันครอบด้วย unit test ของ feat-116/117/122 (รวม
   full-cycle test ใน `runtime/scene-features.test.ts`) และภาพจากเซสชันเบราว์เซอร์ของ feat-122
   แต่ยังไม่มี e2e ที่ยืนยันเป็นภาพรายข้อ

## Defect ที่พบระหว่างตรวจ

### 1. หยุดชั่วคราวแล้วตัวละครยังขยับ (แก้แล้วในงานนี้)

`three-view.tsx` เส้นทางใหม่เดิน `mixer.update(delta)` ด้วย delta ที่ไม่เป็นศูนย์ตอน `paused`
คลิปแบบ loop (Idle/Work/CarryIdle/Eat) จึงเล่นต่อทั้งที่กดหยุดแล้ว ขัดกับสัญญา v1 §2
แก้โดยส่ง delta 0 และ blend 0 ให้ทั้งการขยับตัวและ mixer เมื่อไม่ได้ `running`
ยืนยันด้วยค่าที่วัดได้: พิกเซลเปลี่ยน 0.000% ใน 2.5 วินาทีหลังกดหยุด

### 2. แผงตั้งค่าแสงไม่ถูกต่อเข้าแอป (ยังไม่แก้ — เป็นของสาย lighting)

`src/components/preview-3d/lighting/settings-panel.tsx` (feat-120) มี unit test ครบแต่
**ไม่ถูก mount ที่ไหนเลยในแอป** (`grep` ทั้ง `app/` และ `src/components/` พบเฉพาะไฟล์ตัวเองกับเทสต์)
ผลคือ:

- ผู้ใช้เปลี่ยนเวลา/พิกัด/ทิศเหนือไม่ได้เลย ฉากใช้ค่าเริ่มต้นกรุงเทพฯ กับเวลาเครื่องเท่านั้น
- QA เข้าถึง fixed-clock mode ที่ feat-120 ทำไว้ไม่ได้ ต้องตรึงเวลาเครื่องด้วย `page.clock` แทน
- `use-lighting-store` ไม่มีผู้ใช้งานจริงนอกสาย lighting เอง

ไม่แก้ในงานนี้เพราะเป็น private scope ของสาย lighting (Agent 2) และการ mount ต้องแก้หน้า
playground ซึ่งอยู่นอก write_scope ของ feat-123
