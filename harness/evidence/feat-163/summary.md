# feat-163 — badge สถานะตัวละครตรงตามแบบ 6 หมุด

แบบอ้างอิงจากผู้ใช้ (2026-11-05): หมุดหัวกลมปลายแหลมสั้น 6 สี — รอคิว (เก้าอี้), สั่งอาหาร (คลิปบอร์ด), รออาหาร (ฝาครอบ), กำลังกิน (จาน+ส้อม+มีด), ชำระเงิน (บัตร+เหรียญ), ออกจากร้าน (ประตู+ลูกศร)

## ต้นเหตุที่ไม่ตรงแบบ
- รูปทรงตัดด้วย `clip-path: polygon(...)` 10 จุด → ขอบเหลี่ยม ปลายเป็นตัว V ยาวตั้งแต่ 54% ของความสูง
- ไอคอนในกล่อง 30px แต่ตัวภาพกินแค่ ~40% ของความกว้าง badge และจัดกลางทั้งกล่องรวมปลาย จึงอยู่ต่ำ
- รายละเอียดหาย (เส้นประกาย, ผัก/มะเขือเทศ, เหรียญซ้อน) และไม่มีสถานะ "ออกจากร้าน" — สีส้มอิฐถูกใช้กับ "พนักงานพัก"
- 3 ที่วาดแยกกัน (WebGL overlay, React bubble, canvas fallback) หน้าตาไม่ตรงกัน

## แก้
- `src/components/simulation/thought-badge-art.ts`: path SVG ชุดเดียว (viewBox 100×112) ใช้ทั้ง SVG string และ canvas ผ่าน `Path2D`
