- **ถัดไป**: feat-093 (วิเคราะห์ทั้งวัน + หาจำนวนพนักงาน + เล่นช่วงพีค) → feat-094 (แผง 3 ส่วนตามร่าง + การ์ดคำตอบ); gate feat-093 ต้องยืนยันเกณฑ์ "กำลังดี" และค่าตั้งต้นใน PRD §9 ข้อ 28
