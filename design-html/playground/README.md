# วางร้าน — Playground POC V1

เปิด `index.html` ในเบราว์เซอร์ได้ทันที โดยไม่ต้องติดตั้งแพ็กเกจหรือมีเซิร์ฟเวอร์

สิ่งที่ทำได้ใน POC นี้:

- ระบุความกว้างและความลึกของร้าน (2–30 เมตร)
- วางโต๊ะ เก้าอี้ ชั้นวาง และเคาน์เตอร์ แล้วลากย้ายบนกริด 1 เมตร
- เลือกชิ้นงานเพื่อหมุนหรือลบ
- ซูมเข้า–ออก Artboard 2D และภาพตัวอย่าง 3D ได้ พร้อมปุ่มปรับให้พอดี
- กันการวางชิ้นงานทับกันหรือออกนอกขอบพื้นที่
- ลากทางเข้าตามขอบ Artboard ได้โดยตรง หรือเลือกผนังและตำแหน่งแบบละเอียดจากแถบด้านข้าง
- บันทึกผังลง localStorage อัตโนมัติ พร้อมย้อนกลับและเริ่มใหม่
- เลือกผังเริ่มต้นสำหรับคาเฟ่หรือร้านค้าปลีก แล้วปรับต่อได้
- สลับจาก Artboard 2D ไปดูภาพ Isometric 3D ที่สร้างจากผังเดียวกัน

มุมมอง 3D ในรุ่นนี้เป็นภาพสรุปเพื่อช่วยเห็นสัดส่วนและบรรยากาศของร้าน ไม่ใช่แบบก่อสร้างหรือภาพวัสดุสมจริง

โฟลเดอร์ `assets/` เก็บภาพประกอบชุดเดิมจาก Landing Page ไว้สำหรับต่อยอดหน้า Landing Page ในรอบถัดไป
